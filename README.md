# `.github` — Organización Central de `feversani-labs` ⚙️☁️

Este es el repositorio especial de configuración global ([`.github`](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)) de la organización [**`feversani-labs`**](https://github.com/feversani-labs), donde centralizo mi portafolio de **Cloud Architecture, Infrastructure as Code (Terraform) & DevOps Engineering**.

## 📁 Estructura del Repositorio

```text
.github/
├── profile/
│   └── README.md    # Portada pública de la organización (visible en github.com/feversani-labs)
└── README.md        # Documentación interna de este repositorio de configuración
```

## 🎯 Propósito

1. **Perfil Público de la Organización ([`profile/README.md`](./profile/README.md)):** Renderiza automáticamente la página principal de presentación de [**@feversani-labs**](https://github.com/feversani-labs), incluyendo el catálogo modular de arquitecturas en AWS, principios de diseño (ADRs) y guías de despliegue rápido.
2. **Estandarización de la Organización:** Punto central para alojar configuraciones por defecto heredables por todos los repositorios de laboratorio (plantillas de *Issues/PRs*, políticas de seguridad y *Reusable Workflows* de GitHub Actions).
